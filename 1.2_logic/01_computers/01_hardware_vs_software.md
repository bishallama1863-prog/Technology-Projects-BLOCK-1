# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Ans: Hardware refers to the physical, tangible components of a computer system that yo can see and touch. This includes internal parts like the Central processing unit(CPU), motherboard, random-access memory(RAM), and hard drives, as well as external peripherals like monitors, Keyboards and mice. Hardware provides the physical structure and processing power necessary for a computer to function, acting as the foundation upon which all the digital operations are executed. 
## Explain Software
Write **at least 50 words** explaining what software is.
---
Ans: Software is a collection of instructions, data, and programs that tell a computer's hardware what to do. Unlike hardware, it is intangible and cannot be physically touched. Software is typically divided into two main categories: system software(like the operating system that manages hardware resources) and application software (like web browsers or word processors). Essentially, software acts as the "brain" or set of the commands that brings the physical hardware to life.
## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Ans: Hardware and software interact through a continuous cycle of instructions and execution. When a user interacts with application software, the software translates those actions into a machine code binary instructions(1s and 0s). These instructions are sent to the CPU (hardware) via the operating system. The hardware then processes these electrical signals to perform the requested tasks, such as displaying text on a screen or saving a file to a drive. Neither is fully useful without the other.
